设计依据：`design-reference.png`，来自用户选定的第 3 张 ImageGen 原型。原始文字需求保存在 `requirements-source.txt`。

| 成熟度管理 | 上传/相机入口、模型适配、原图/标注图、列表、筛选、对比、结果与照片包、PDF | 果实数量、成熟度分布、平均置信度随识别与档案持久化，JSON/PDF 导出保留；演示图片上传已在浏览器完成，统计为 2 个、1 成熟 / 1 半成熟、90.0%，见 qa/recognition-summary.png；实际 YOLO 权重未提供，真实推理未验收 |
| 生长档案 | 图文记录、环境快照、事件时间轴、设备和茬次筛选、跨记录对比、PDF/CSV/照片包、任务提交 | 浏览器截图入档、档案关联任务；PDF 七项曲线与中文视觉检查 |
| AI 日志 | 判断和控制记录、来源编号、异常、标记问题、CSV、复盘 PDF | 问答日志按所选设备保留当时环境与知识原文快照；识别和指令事件关联各自结果。13 项测试通过，证据展开截图 qa/log-evidence.png；历史日志不回填虚构快照 |
| 知识库 | Neo4j Cypher 检索、原因与措施、引用、交互关系图、来源详情、收藏、经验新增、探究记录、截图 | 浏览器保存后读回；不同问题产生不同来源；Neo4j 独立实例真实存储、跨驱动读回、直接关系修改、停库 503 和重启持久化已验证；无命中返回空图谱。未接入 LLM，不宣称完整生成式 RAG |
| 课程实训 | 12 项实训、课时、发布、领取、提交文本/照片/数据、教师评分评价、积分与勋章 | API 领取/提交/角色限制/评价测试；浏览器档案提交到课程 |
| 多设备 | 新增、分组、茬次、数据通道、配置、汇总与对比导出 | CRUD 与角色限制测试、浏览器多设备表格；示例为 3 台设备 |
| 移动端 | 监控、拍照、记录、问答、我的；任务、预警与设备从个人中心进入 | 390×844 浏览器布局无横向溢出。响应式网页，不是原生 APP 安装包；相机/语音依赖浏览器权限，未访问用户实体摄像头 |
| 留存与导出 | SQLite 持久化、设备/茬次/时间关联、分钟/小时 SQL 聚合、原图标注图、照片包、PDF、CSV、XLSX | 持久化读回、导出文件签名与 PDF 视觉检查；长周期数据按实际采集积累 |
| 身份 | 教师、学生、管理员、家长四种本机角色；非演示模式从环境读取密码 | API 授权测试。演示角色不等于多学校多学生生产账户系统 |

## 验证结论

本地可运行软件、图谱界面及 MQTT 协议链路已验证。真实设备动作、真实训练模型准确率、原生移动安装包、多学校生产身份体系不在已验收范围。没有凭据或模型时明确保持未连接/未配置状态。

## MQTT 协议更新

已按用户番茄种植架 V1.1 / r18 文档更新。backend/config/mqtt.yaml 为权威配置；固定根主题、四项订阅、九种命令和字段单位已适配。17 项测试通过，未连接真实 Broker 或硬件。水位采用 cm，EC 由 μS/cm 换算为 mS/cm；固件无通风、水雾命令，不能宣称此设备支持。
