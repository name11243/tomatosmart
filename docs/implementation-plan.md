# 实现范围与设计基准
视觉基准：用户选择的第 3 张知识图谱原型 ../prototypes/03-knowledge-graph.png。
视觉：深绿顶栏、米白工作区、窄侧栏、左图谱右解释，桌面 1488×1056 原图比例。
内容：主工作区查询与知识关系；来源解释；环境上下文；保存探究记录。
交互：图谱缩放与节点高亮；抽屉平滑展开；选中导航与按钮反馈。尊重减少动画设置。
技术：Vue 3 / Vite / ECharts / Remix Icon，FastAPI / SQLite / Paho MQTT。

需求覆盖：
- 总览七项参数、设备模式、快照、拍照、识别摘要、预警。
- 物联网历史曲线、四执行器、手动自动、CSV/Excel、事件、曲线截图。
- 成熟度上传识别、原图标注图、置信度、筛选、对比、采摘报告。
- 生长档案时间轴、图文、快照、茬次/设备对比、PDF/CSV、关联任务。
- AI 日志查询、来源、异常、标记、导出、复盘。
- 知识问答、来源检索、交互图谱、收藏、经验入库、探究记录、截图。
- 12 项实训、教师发布与评价、学生领取提交、照片与报告。
- 设备新增分组、配置、多设备汇总、角色控制。
- 移动布局覆盖监控、拍照、记录、预警、知识、任务和个人中心；网页应用，不声称原生安装包。
- 数据按设备/茬次/时间分类，2 秒模拟采集与真实 MQTT 接收，分钟小时聚合，照片包和报告。
- MQTT 地址端口认证 TLS QoS 客户端标识、遥测/控制/回执主题、测试、连接、断开、回执超时和关联校验。

真实边界：默认演示数据与示例知识。真实成熟度推理需配置 YOLO 权重，真实设备控制需 Broker 与设备回执。不得用模拟成功冒充物理执行。
